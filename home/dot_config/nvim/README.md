# Requirements

- **Neovim:** This configuration is currently developed and tested against **Neovim v0.10.4**. It is known **not** to be fully compatible with Neovim v0.11+ yet due to breaking changes in Neovim or plugin APIs. Please use a v0.10.x release.

- xkb-switch for langmapper.nvim

To switch not only nvim theme, but all themes, install these packages:

```sh
glib2 adwaita-icon-theme gnome-themes-extra
```
